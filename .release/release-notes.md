This change types inputs that Microsoft Graph metadata declares as a nullable reference to one complex type or enumeration and that the previous release typed as any, and stops typing a Graph type as an object where a subtype adds properties: 5,939 input type changes in 756 v1.0 and 1,199 beta generated modules. References whose type declares subtypes (for example identitySet, recipient or deviceAndAppManagementAssignmentTarget), objects whose only property is @odata.type (for example subjectSet, plannerAssignments or booleanColumn) and single-valued navigation properties keep or get type any. Polymorphic positions also stay any: a Graph type is never typed as an object, whether as an input, a nested attribute, a list or set element or a map value, when a type deriving from it in the Microsoft Graph EDMX metadata, directly or through BaseType inheritance, declares a property it lacks.
